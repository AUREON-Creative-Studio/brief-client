BRIEF CRÉATIF — SITE DE QUESTIONNAIRE CLIENT

Fichiers :
- index.html : structure et contenu du questionnaire
- style.css : design responsive premium
- script.js : navigation, validation, palette de couleurs et export des réponses

Pour utiliser :
1. Décompressez le dossier.
2. Ouvrez index.html dans un navigateur récent.
3. Le questionnaire fonctionne sans installation ni serveur.

Palette de couleurs :
Le client peut choisir exactement quatre couleurs avec les sélecteurs natifs (palette complète du système) ou saisir directement un code HEX (#RRGGBB).

Important :
Cette version HTML/CSS/JavaScript fonctionne côté navigateur. Les réponses ne sont pas envoyées automatiquement à votre adresse e-mail et ne sont pas stockées dans une base de données. À la dernière étape, le navigateur télécharge un fichier texte contenant les réponses. Pour recevoir les réponses automatiquement, il faudra ajouter un backend (par exemple PHP + MySQL) ou connecter un service de formulaire.

Branding : identité AUREON intégrée avec le logo fourni (aureon-logo.jfif).
